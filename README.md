# KiraWorld

Private recovery snapshot and development history for Kira World.

This repository deliberately contains source code, tests, controlling
documents, handoffs, configuration schemas, and compact current checkpoints.
It is not a complete mirror of the local Kira workspace. Resident-private
data, conversation histories, model weights, media libraries, large 3D
assets, rendered evidence, caches, recursive backups, and build outputs stay
local unless they receive a separate privacy/license/size review.

Start with:

- `System/Docs/CURRENT_TRUTH_SUPERSESSION_REGISTRY_20260810.md`
- `HANDOFF_FOR_NEXT_CODEX_SESSION.md`
- `System/Docs/CURRENT_TEST_EXECUTION_BOUNDARY_20260811.md`
- `BACKUP_SCOPE.md`

Static candidates and historical documents are not live-feature evidence.
No body is complete until exact Blender/body/save/reload/render evidence is
independently accepted.
