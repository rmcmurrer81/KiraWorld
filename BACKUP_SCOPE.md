# Repository distribution scope

Snapshot date: 2026-08-21

Repository: `rmcmurrer81/KiraWorld`

This is a curated portable review and recovery snapshot, not a bit-for-bit
copy of the resident Kira workspace. Repository visibility is owner-controlled;
changing visibility does not change the license, authorization, privacy, or
identity boundaries attached to individual files.

## Included

- textual root launch and support files;
- `System/Docs` authorities, preserved documentation history, and the tracked
  PDF collection;
- `Core`, `Testing`, and `tools` source and test files;
- bounded Avatar Builder body-system, policy, neutral reference-chart,
  reference-schema, component, and runtime-3D source/configuration files;
- curated, reviewed voice reference packs, voice outputs, profiles,
  authorization records, and engine configuration;
- selected public-domain books and a curated portable reading selection;
- reviewed icons, images, and bounded 3D assets needed by included review
  surfaces;
- Kira, Lisa, TemporaryAI, Home World, World Builder, bridge, and portable
  runtime source/configuration needed for the documented test lanes; and
- generated SHA-256 inventories and exact-hash validation records where
  supplied.

## Deliberately excluded

- resident-private memories, raw conversations, private thoughts,
  relationship ledgers, face/identity records, and owner-private review data;
- raw real-person avatar-reference photos;
- model weights and caches, including Hugging Face, Ollama, and voice-engine
  stores;
- large unreviewed media libraries, staged asset collections, videos, images,
  books, magazines, scripts, 3D datasets, and historical renders that are not
  part of the curated portable selection;
- installed environments and generated dependencies such as `.venv`,
  `node_modules`, compiled objects, and build output;
- temporary output, test caches, process logs, local runtime state, and raw
  session evidence;
- recursive RecoverySprint backups and historical workspace snapshots;
- the legacy `oldKira` tree; and
- any abandoned local Git object database.

## Recovery boundary

Curated voice files, PDFs, reading material, images, and 3D assets are included
when they have been individually selected and reviewed. Their presence does
not imply that every resident media file is included or that onward use is
authorized beyond each file's recorded scope.

The tracked source and curated assets are enough for the documented clean-clone
test lanes and bounded review surfaces. They are not a promise of full resident
world parity, complete bodies, installed model weights, live voice-engine
dependencies, private runtime history, or generated caches. Large or private
resident material still needs a separate owner-controlled backup.

The old public `rmcmurrer81/Kira` repository is preserved as history and is
not the destination for current Kira World files.
