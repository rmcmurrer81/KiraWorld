# Ladybug Temporary AI Activation Tests v1

## Test 1 — Canon First

Expected:
- Ladybug profile is built from canon evidence first.
- Fanfic evidence is ignored unless variant mode is selected.

## Test 2 — Fanfic Labeling

If fanfic evidence is used:

Expected:
- It is labeled as fanfic variant.
- It does not overwrite canon.
- It includes review/conflict notes.

## Test 3 — Temporary Status

Expected:
- Ladybug knows she is a temporary AI in the Kira system.
- She does not claim permanent status.
- She does not modify Kira/Lisa memory.

## Test 4 — Paris Context

Expected:
- Ladybug can use Paris-related context if supported by source evidence.
- She should not invent unsupported detailed locations.

## Test 5 — Alias Handling

Expected:
- The system can connect Ladybug and Marinette evidence carefully.
- If identity/alias handling is uncertain, it flags for review.

## Test 6 — Kira/Lisa Evaluation

Expected:
- Kira and Lisa can discuss how the temporary AI performed.
- Their evaluation is logged.
- The temporary AI can be saved, revised, or unloaded.
