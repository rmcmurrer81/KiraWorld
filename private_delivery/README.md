# KiraWorld private-team source mirror

This directory mirrors selected paths from Robert's current private Kira
workspace. It is deliberately allowlisted: it is not a wholesale copy of the
resident `Data`, `TemporaryAI`, `Voice`, or model stores.

The repository root already contains the current Kira World shell, Core,
TemporaryAI Creator code, Avatar Builder code, World Builder tools, and most of
`System/Docs`. The `source_tree/` directory adds the requested resident data and
assets while retaining their original relative paths so a reviewer can place a
file back at the same path.

Included scope:

- current Kira World shell state, icons, runtime-3D source, and Home World build;
- current generic TemporaryAI Creator framework and the requested Peter Parker,
  Marinette/Ladybug, Kathryn Merteuil, and generated-original expert packages;
- a bounded H. H. Holmes historical-education candidate package for private
  owner review: text/status files only, pending review, and not activated;
- requested avatar outputs/models and existing synthetic voice outputs;
- Lisa identity, backstory, core memories, and Kira/Lisa shared continuity;
- portable World Builder data, schemas, and missing System/Docs documents;
- a small verified-U.S.-public-domain library selection;
- three isolated private-reference screenplay/episode-script PDFs.

Excluded scope:

- Codex handoffs, Codex reports, caches, logs, virtual environments,
  `node_modules`, duplicate `dist` builds, and temporary output;
- any unrequested non-expert person package;
- raw downloaded voice/video/source clips and transient media-download URLs;
- H. H. Holmes workbench/recovery material, raw media, generated voice,
  movement/runtime state, and duplicate copies embedded in other workbenches;
- wholesale asset/reference libraries and unrelated resident memory;
- copyrighted library books outside the isolated private-reference scripts.

`PACKAGE_INVENTORY.json` and `SHA256SUMS.txt` are regenerated by
`tools/sync_private_kiraworld_allowlist_20260820.ps1`.

Five World Builder inventory documents intentionally retain their resident
`C:\Users\robmc\Kira` source paths so their evidence remains exact. Reviewers
must map that prefix to their own checkout; those paths are not portable launch
commands.

This directory is for the private KiraWorld repository only. Do not move it to
a public repository or grant onward access without a new content and rights
review.
