# Paris Notebook World Blueprint Rules

## Rule

No new location geometry should be built until a blueprint/reconstruction note exists for that location.

The blueprint must come before code. It should identify the reference images used, the intended floor/section layout, approximate dimensions, vertical flow, entry points, and known unknowns. If a feature is guessed, label it as an estimate instead of presenting it as fact.

## Bakery Rebuild

The failed bakery model was removed from the live preview code on 2026-06-29. Do not delete the bakery reference images, bedroom images, screenshots, or source folders. They are required for the future blueprint-first rebuild.

Before rebuilding the bakery, create a dedicated blueprint document with:

- Exterior elevation plan for the corner storefront, upper apartments, mansard/attic level, roof, and rooftop balcony.
- Ground-floor bakery plan with the correct corner door, transparent windows, customer area, display cases, production kitchen, oven area, and home stair access.
- Upper-floor apartment plan.
- Marinette bedroom/loft plan with the balcony hatch positioned over the bed.
- Vertical section showing ground floor, family apartment, Marinette attic room, balcony, roof, stairs, hatch, and bed alignment.
- A reference checklist matching every major modeled feature to one or more supplied pictures.

## Louvre Rebuild

The Louvre courtyard/interior may continue only from a blueprint note. Current priority is the Louvre Pyramid exterior and under-pyramid lobby.

Required Louvre blueprint sections:

- Cour Napoleon scale anchors: main pyramid, small pyramids, reflecting pools, queue stanchions, palace wings, and visitor paths.
- Under-pyramid lobby: glass pyramid overhead, concrete upper deck, coffered underside, columns, stairs, escalators, spiral stair/ramp, signs, queue areas, and visitor floor.
- Movement plan: courtyard walking area, lobby walking area, and explicit transition key/portal.
- Known unknowns: exact floor plan details, shop/ticket/security layouts, restricted areas, and any geometry inferred from photos.
