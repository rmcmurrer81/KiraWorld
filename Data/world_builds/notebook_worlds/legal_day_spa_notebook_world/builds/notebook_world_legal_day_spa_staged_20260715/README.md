# Legal Day Spa Separate Notebook World

Status: staged for standalone review; not approved for Home World.

Run `Start_Legal_Day_Spa_Notebook_World.bat` from the Kira project root. The launcher is code-pinned to `pinned_build_manifest.json` and verifies the registration, notebook-index anchor, entry HTML, scene and approval metadata, five exact GLBs, and required Three.js modules before binding localhost. It serves only those manifest-bound URLs. It does not follow the mutable latest pointer, expose the rest of the workspace, or start Kira, Ollama, voice, the Kira World Shell, or Home World. Any byte or path change fails closed.

The 12-second combined resource smoke passed, with 18.779 GB minimum available system RAM and 7,288 MB peak whole-system VRAM use. This is not evidence for a several-hour autonomous session or a slow memory leak. The 64 GB gate, long soak, Kira route, visual-realism, missing-prefab, and Robert approval requirements remain.

The spa was not placed in Home World, and the strip mall was not deleted or replaced. Separate tablet and embodiment-evidence improvements may update Home World independently of this notebook-world staging.
