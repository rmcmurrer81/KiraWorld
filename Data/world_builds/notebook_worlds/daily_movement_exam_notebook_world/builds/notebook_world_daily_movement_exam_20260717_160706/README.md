# Daily Movement Exam notebook world

This is a separate, lightweight, private notebook-world preview. It contains
one compact original room, a short hallway, one open staged door, an L-shaped
corner obstacle, couch, bed, chair, table, tablet, cup, robe hook and static
robe silhouette, and a clear exercise area.

Run `Start_Daily_Movement_Exam_Notebook_World.bat` from the project root. The
launcher verifies the code-pinned manifest and every served byte before it
binds loopback. It serves only the exact preview, scene contract, and required
Three.js modules.

The preview loads **zero people**. Owner walk review moves only the camera. The
cyan moving capsule is a static-clearance probe, not Kira. Yellow disks are
future subject-choice-only stations; they do not invoke a body skill. Door use,
sitting, lying down, getting up, tablet/cup contact, reading, writing, drinking,
robe dressing, hand raising, and floor exercise remain unimplemented and
blocked.

The next supervised runtime stage must separately prove Kira's choice,
navigation, grounding, collision avoidance, rig compatibility, contact, and
safe stop for each attempted action. This preview does not register a runtime
destination or mutate Home World.
