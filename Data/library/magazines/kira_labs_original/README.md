# Kira World original visual magazine covers

This folder contains two original synthetic cover designs created for Kira
World's public, non-adult library:

- `kira_history_issue_27_cover.png` — **Kira History**, “The Year the Sky
  Changed.”
- `kira_entertainment_issue_07_cover.png` — **Kira Entertainment**, “Stories
  Become Worlds.”

Compact WebP editions are included for the public Kira World reading-room UI.
The PNG editions remain the full-resolution masters.

The covers use fictional environments and synthetic figures. They contain no
photographs of real people, third-party magazine scans, third-party logos, or
licensed fictional characters. They are intended as Kira Labs visual-library
assets and as templates for future illustrated issues.

Existing commercial magazines in the private local library are not included
in this public cover pack. A local file's presence does not establish public
redistribution rights.
