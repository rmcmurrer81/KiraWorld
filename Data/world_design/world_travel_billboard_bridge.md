# World Travel Billboard Bridge

## Purpose

Use clear walk-in travel billboards as a temporary bridge while the AIs learn the full TARDIS call, entry, console, and destination workflow.

## Rules

- A billboard is a visible destination promise, such as "Visit Paris" or "Play Capture the Flag."
- Walking into the billboard transfers the user or AI to the target world and logs the intent, source world, destination world, and return point.
- Every transfer should create a learning record that can later train the TARDIS workflow.
- A matching return billboard or exit marker must exist in the destination world until TARDIS navigation is reliable.
- A world remains active while Robert or at least one active AI is present there.

## TARDIS Goal

- The TARDIS should appear only when someone calls it or arrives in a world with it.
- Opening the exterior door should reveal the console room first.
- Crossing the exterior doorway threshold transfers the traveler into the interior.
- The interior console screen should show available worlds, construction worlds, temporary AI creation, and world-builder tools.
- Leaving through the interior exit should return to the current parked exterior location.

## AI Learning Sequence

1. Decide on a destination.
2. Try the billboard if TARDIS control is not learned yet.
3. Log the billboard choice as a successful travel example.
4. Practice calling the TARDIS from the same intent.
5. Walk to the TARDIS, open the door, step through, use the console, select the destination, and exit in the destination world.

## Capture-The-Flag Access

- Add a game billboard near the home-world library or strip mall.
- Add a return billboard near the safe base in the battleground world.
- Use the same travel log format so AIs learn that game worlds are optional destinations.
