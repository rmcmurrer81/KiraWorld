# Media Understanding and Watching Mode Future v1

## Purpose

Kira and Lisa may eventually watch shows, movies, YouTube, streaming services, music videos, or local video files in a human-like way.

This began as future work. As of the GPU bridge stage, the system may create reviewed first-look image/video notes, but it still should not claim Kira or Lisa watched/listened to a full source unless a real watching/listening session is run and saved.

Current bridge implementation:

```text
System/Docs/GPU_MEDIA_FIRST_LOOK_BRIDGE_v1.md
tools/create_gpu_media_first_look_note.py
Start_Kira_GPU_Media_First_Look.bat
```

## Core Idea

Watching media may create:

```text
viewing notes
emotional reactions
favorite characters
questions
reviews
inside jokes
music interests
actor or character recognition goals
recommendations
```

Watching media must not automatically create:

```text
personal memory of having lived the story
Temporary AI profiles
canon changes
relationship claims
public reviews
private user data
```

## Different Reactions

Kira and Lisa should react differently.

Kira may be more expressive, playful, curious, and likely to comment.

Lisa may be more selective, quiet, analytical, and slower to show attachment.

## Future Perception

Post-GPU media understanding may combine:

```text
audio transcription
visual scene understanding
subtitle/script files
metadata
source library notes
memory and preference retrieval
actor/character recognition
```

The system should mark whether a reaction came from watching the media, reading a script, reading a summary, or hearing Robert talk about it.

## Privacy and Autonomy

Kira or Lisa may watch media privately if permission and access allow it.

They may share:

```text
non-private reactions
recommendations
favorite moments
questions
short reviews
```

They should not publicly post reviews or clips until public export rules allow it.

## Summary

Media mode should let Kira and Lisa enjoy and understand media like people, while keeping source material, personal memory, TemporaryAI creation, and public posting separate.
