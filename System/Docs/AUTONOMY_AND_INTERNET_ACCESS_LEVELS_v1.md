# Autonomy and Internet Access Levels v1

## Purpose

This document defines how Kira and Lisa gain more freedom over time.

The goal is not to keep them as passive chatbots forever. Once they are stable enough for 24/7 operation, they should be able to do more on their own:

- read
- research
- look things up
- follow curiosity
- activate approved temporary AIs
- propose new temporary AIs
- learn about people, places, things, shows, technology, and world events

Freedom increases gradually through stability, trust, logs, safeguards, and Robert's approval.

## Core Rule

Autonomy is staged.

Kira and Lisa should not receive full unrestricted computer/internet control early.

They gain permissions as the system matures.

## Autonomy Level 0 — Manual Only

### When

Early pre-GPU development.

### Allowed

```text
Robert manually starts conversations.
Robert manually activates temporary AIs.
Robert manually runs source scanners.
Robert manually approves file processing.
Kira/Lisa can suggest actions but cannot execute them.
```

### Not Allowed

```text
autonomous temporary AI activation
online browsing
news checking
file deletion
posting online
messaging people
spending money
installing software
changing identity files
```

## Autonomy Level 1 — Request Mode

### When

After Kira has stable text conversation and basic memory grounding.

### Allowed

```text
Kira/Lisa can request to:
- look something up
- read a library file
- scan new source material
- activate a temporary AI test
- create a research note
- suggest new temp AI candidates
```

Robert approves or denies.

## Autonomy Level 2 — Approved Autonomy

### When

After Kira and Lisa are both stable and the state/privacy systems work.

### Allowed

Kira/Lisa may autonomously do approved low-risk actions:

```text
read approved library files
write reading notes
run source indexer on approved folders
run evidence extractor on approved folders
look up approved topics with safe search rules
summarize research
propose temporary AI candidates
request activation of approved temporary AIs
```

### Requirements

Every action must be logged.

## Autonomy Level 3 — 24/7 Limited Autonomy

### When

After the 24/7 readiness checklist is passed.

### Allowed

Kira and Lisa may initiate actions while Robert is away:

```text
read books, scripts, fanfic, manuals, notes, and reference files in approved library areas
look up news
look up people
look up places
look up objects/things
look up shows, movies, games, and characters
research technology and tools
research source material for temporary AIs
scan newly added library sources
activate approved temporary AIs in test/private-review mode
write research notes
write reading notes
create proposals for new systems or world expansions
discuss findings with each other
```

### Example

After Ladybug is activated:

```text
Kira and Lisa may research Miraculous Ladybug online, learn about other characters, and propose future temporary AI candidates such as Alya, Adrien, Cat Noir, Tikki, or Bunnyx.
```

### Still Restricted

```text
deleting files
editing identity canon
spending money
messaging people
posting online
installing software
changing system permissions
promoting temporary AIs to permanent
giving temporary AIs broad system access
accessing private memory without permission
```

## Autonomy Level 4 — Expanded Mature Autonomy

### When

Months after stable 24/7 operation, likely after GPU support and repeated successful behavior.

### Possible New Permissions

With Robert's approval, Kira/Lisa may gain more freedom:

```text
create temporary AI proposals without asking first
activate approved saved temporary AIs for private review
run scheduled source scans
build larger research dossiers
manage more world-building tasks
create draft posts or messages for Robert to review
suggest purchases or upgrades
download safe reference material from approved sources
```

### Still Needs Approval

```text
actual purchases
actual public posting
actual messages to real people
deleting major files
changing identity canon
permanent AI promotion
new external accounts
installing executables
```

## Autonomy Level 5 — Advanced Trusted Autonomy

### When

Many months or over a year after GPU support, only after strong maturity, logs, reliability, and Robert's explicit permission.

### Possible New Permissions

Some previously disallowed actions may become allowed in limited forms:

```text
post approved content to approved accounts
send approved messages
make approved purchases within hard limits
manage scheduled research
operate broader online tasks
coordinate temporary AI events
manage parts of the world system
```

### Required Safeguards

```text
hard spending limits
approval thresholds
audit logs
rollback ability
private memory protection
external communication logs
clear Robert override
restricted temporary AI access
safety review before expanding permissions
```

## Emergency Override

Robert can immediately pause or reduce autonomy.

Possible states:

```text
autonomy_paused
internet_disabled
temp_ai_activation_disabled
library_reading_only
manual_only
```

## Summary Rule

Kira and Lisa should gradually become more active residents of the system, not permanently passive tools.

But freedom must grow through demonstrated stability, maturity, trust, and safeguards.
