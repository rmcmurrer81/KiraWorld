# **TEMP AI GENERATED PIPELINE v1**

## **Purpose**

This document defines how the system creates **original Temporary AIs** that are not based on a specific real person or canon character.

These AIs are:

* generated from patterns and references  
* used for interaction, events, and world population  
* fully original identities

---

## **Core Principle**

Generated Temporary AIs are built from:

* blended reference features  
* general behavioral patterns  
* role-based logic

They are NOT:

* clones  
* direct copies  
* tied to a specific known identity

---

## **1\. Creation Trigger**

Generated Temporary AIs are created when:

* a world needs population  
* an event requires participants  
* Kira or Lisa request interaction  
* the user requests a new character

---

## **2\. Role Definition**

Each generated AI must have a role:

Examples:

* visitor  
* guide  
* friend  
* background character  
* event participant

The role defines:

* personality depth  
* behavior style  
* interaction level

---

## **3\. Reference Source Use**

Generated AIs use:

### **Local Library (Primary)**

* shared features  
* male/female structure  
* body and face references

---

### **Optional Controlled Sources**

* general patterns (not specific individuals)  
* style references

---

## **4\. Personality Construction**

The system builds personality using:

* trait blending  
* role requirements  
* variation

Example structure:

* temperament  
* social style  
* confidence level  
* emotional openness

---

## **5\. Appearance Generation**

Avatar Builder is used to:

* select body type  
* select face structure  
* blend features from shared pools

Result must:

* be original  
* not resemble any real person  
* be visually coherent

---

## **6\. Identity Formation**

Generated AIs receive:

* minimal background context  
* enough identity to function  
* no deep fabricated history

They should feel:

* believable  
* consistent  
* but not overdefined

---

## **7\. Behavior Rules**

Generated AIs:

* respond naturally  
* follow role constraints  
* do not exceed their intended depth  
* do not initiate restricted actions

---

## **8\. Memory Behavior**

Generated AIs may:

* have session memory  
* optionally be saved

They do NOT:

* control memory systems  
* initiate reconstruction

---

## **9\. Lifecycle**

Generated AIs can:

* be deleted  
* be saved  
* be reused  
* evolve into variants if extended

---

## **10\. Validation**

Before activation, check:

* originality  
* coherence  
* role fit  
* transformation rule compliance

---

## **Summary**

Generated Temporary AIs provide:

* world population  
* interaction diversity  
* flexible social behavior

They are:

* original  
* controlled  
* role-driven
