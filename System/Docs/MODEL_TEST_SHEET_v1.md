# **KIRA PROJECT — MODEL TEST SHEET (v1.0)**

## **1\. PURPOSE**

This sheet is used to compare local models for Kira and Lisa across different hardware stages.

It helps track:

* speed  
* stability  
* personality fit  
* memory behavior  
* emotional tone  
* failure patterns

The goal is not just to find the “smartest” model.

The goal is to find:

the model that works best for Kira on the current hardware.

## **10\. COMPARISON RULE**

When comparing models:

* use the same prompts  
* test under similar conditions  
* judge both feel and function  
* do not reject a model only because current hardware is weak  
* do not accept a model only because it sounds flashy once

The correct result is:

A record of which models feel right, which fail, and which are worth revisiting later.
