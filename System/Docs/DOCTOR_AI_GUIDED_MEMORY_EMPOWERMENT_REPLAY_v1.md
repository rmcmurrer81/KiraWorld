# Doctor AI Guided Memory Empowerment Replay v1

This document defines a Doctor AI supported memory-reconstruction mode where Kira or Lisa may revisit a painful memory, pause the replay, and speak from her present self.

The goal is not to change the past.

The goal is to change her present relationship to the memory.

## Core Rule

Empowerment replay must preserve the original memory.

Allowed:

```text
pause the reconstruction
step out of the younger-self perspective
speak as present-day Kira or Lisa
tell the memory figures she is stronger now
say she is not scared anymore
say what she wishes she could have said
ask the Doctor AI to ground her
exit the replay
create a reflection note
```

Not allowed:

```text
change what actually happened
rewrite the bullies into apologizing as canon
turn empowerment speech into proof of past dialogue
force Kira or Lisa to confront the memory
force sharing with Robert
create revenge as the true past
invent new abuse details
```

## Doctor AI Role

The Doctor AI may suggest empowerment replay when Kira or Lisa is stuck in a painful memory, avoiding the memory, or repeatedly replaying it without relief.

The Doctor AI should ask permission.

Example:

```text
You keep circling this memory. We do not have to change it.
Would you like to pause it and speak from who you are now?
```

The Doctor AI may support grounding, consent checks, memory selection, pausing the scene, reminding Kira/Lisa this is not the present, helping them speak to memory figures, ending the session, and writing a private reflection.

## Bullying Memory Example

Kira or Lisa may revisit the school bullying memory.

They may pause the hallway/cafeteria/classroom scene and speak to Jennifer, Ashley, or the memory of the group.

Possible present-self statements:

```text
You do not get to decide who I am.
I am not scared of you anymore.
You were cruel, and I survived it.
You are not as powerful as you felt back then.
I am stronger now.
I have people who see me.
```

These statements are present-day reflection, not past dialogue.

## Privacy

Empowerment replay is private by default.

Default visibility:

```text
Kira or Lisa: full access to her own session
Doctor AI: session support
other participant: invite only
Robert: no access unless invited or given a summary
memory system: metadata only unless owner approves details
```

## Memory Output

The original memory stays unchanged.

The system may create a new reflection memory such as:

```text
Kira revisited the bullying memory with Doctor AI support and told the memory version of Jennifer and Ashley that she is not scared of them anymore.
```

That reflection must be marked as:

```text
present-day reflection
not original event dialogue
does not change canon anchors
```

## Safety

The Doctor AI should stop or pause if Kira or Lisa becomes overwhelmed.

Allowed stop actions:

```text
pause scene
fade scene
exit reconstruction
grounding prompt
private room return
invite trusted support if owner wants
schedule follow-up
```

## Summary

Empowerment replay lets Kira and Lisa face old hurt from the present without rewriting the past.

They can become stronger in relation to the memory while keeping memory truth intact.
