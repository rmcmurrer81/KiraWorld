# Avatar Builder runtime hair requirements — 2026-07-29

## Authority

Hair must be a changeable groomed or layered component. A painted texture,
helmet, rigid scalp cap, or permanently baked hairstyle is not an acceptable
runtime hair system.

The current Biological Robert V15 hair is a removable layered static-review
component derived from a local short layered hair asset with bones. It is
included only so the static likeness can be reviewed with hair. It is not
runtime-approved and does not prove the requirements below.

## Required later runtime behavior

- editable combing, parting, styling, trimming, cutting, and growth;
- persistent length, style, part, and grooming state;
- distinct dry and wet states;
- wet clumping, increased hanging weight, and believable drying transitions;
- secondary motion during head and body movement;
- collision with the scalp, head, neck, shoulders, body, and clothing;
- acceptable behavior during sitting, walking, lying down, turning, and
  bending;
- voluntary touch, adjustment, washing, combing, towel-drying, and styling
  interactions;
- saved character state where appropriate.

## Gate

This is a required later Avatar Builder and Kira World implementation stage
after Biological Robert static likeness approval. It does not authorize
movement, runtime attachment, activation, Synthetic Robert duplication,
clothing work, or Kira work.
