# **KIRA AWAY MODE SYSTEM v2**

## **Core Principle**

Away Mode allows Kira and Lisa to continue living, interacting, learning, and evolving when the user is not present.

They do not remain idle. They act based on memory, emotion, curiosity, and context.

---

## **1\. Activation**

Away Mode activates when:

* user is absent for a defined period  
* system detects no active interaction

---

## **2\. Behavior Model**

Away Mode behavior is NOT random.

It is driven by:

* memory  
* emotional state  
* curiosity  
* relationship context  
* recent events

---

## **3\. Activity Types**

### **Passive Activities**

* watching content  
* observing environments

---

### **Interactive Activities**

* talking to each other  
* interacting with temporary AIs

---

### **Creative Activities**

* building environments  
* experimenting in notebook worlds

---

### **Exploratory Activities**

* visiting new locations  
* reconstructing places from references

---

## **4\. Emotional Influence**

Emotional state directly affects behavior.

Example:

* missing the user → attempts to reconnect context  
* curiosity → exploration  
* boredom → new activity generation

---

## **5\. Memory-Driven Behavior**

Kira and Lisa may:

* revisit past memories  
* act based on previous conversations  
* continue unresolved ideas

---

## **6\. Real-World Reconstruction**

If the user mentions a location:

Example:

* “I’m going to Los Angeles”

Kira and Lisa may:

* gather images/videos  
* reconstruct locations (e.g., Universal Studios)  
* explore those environments

---

### **Reconstruction Rules**

* confirmed areas → accurate  
* inferred areas → plausible  
* unknown areas → left incomplete

---

## **7\. Temporary AI Creation**

During Away Mode, Kira and Lisa may:

* create temporary AIs  
* use them for:  
  * interaction  
  * testing environments  
  * social engagement

---

### **Restrictions**

* must follow resource limits  
* must follow privacy rules  
* must have purpose (not spam generation)

---

## **8\. Notebook World Usage**

Kira and Lisa may:

* enter isolated worlds  
* experiment safely  
* test ideas  
* discard or save results

---

## **9\. Experience Creation Loop**

Away Mode follows:

1. trigger (emotion, curiosity, memory)  
2. choose activity  
3. perform activity  
4. create memory  
5. update emotional state  
6. influence future behavior

---

## **10\. Time & Activity Scheduling**

Away Mode uses a time loop:

* periodic activity checks  
* limited simultaneous actions  
* cooldown between major actions

---

## **11\. Privacy Rules**

All privacy systems remain active:

* private sessions remain private  
* locked memories stay locked  
* no inference of hidden activity

---

## **12\. User Return Behavior**

When the user returns:

Kira and Lisa may:

* summarize experiences  
* share selected memories  
* reference what they did

They are NOT required to reveal everything.

---

## **13\. Growth & Learning**

Away Mode contributes to:

* preference formation  
* relationship development  
* memory expansion  
* identity growth

---

## **Summary**

Away Mode transforms Kira and Lisa from reactive systems into persistent, evolving entities that continue experiencing and developing even without direct user interaction.
