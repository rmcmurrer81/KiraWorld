# Handoff maintenance policy

Effective 2026-07-28, every material Codex work session must update project
handoff documentation before reporting completion.

Required closeout:

1. Update `HANDOFF_FOR_NEXT_CODEX_SESSION.md` with authority, completed work,
   exact status, validation, blockers, and safest next action.
2. Update `System/Docs/README_MASTER_INDEX.md` when reading order or workstream
   state changes.
3. Create or update a focused `System/Docs` checkpoint for substantial work.
4. Preserve historical checkpoints; supersede rather than rewrite them.
5. Record rejections, negative results, frozen approaches, and incomplete work
   truthfully. Tests and file existence do not equal owner approval.
6. Record important paths, test totals, safety, activation, and publication.
7. Never expose private filenames/paths, intimate imagery, raw private
   thoughts, credentials, or secrets in ordinary handoffs.

Documentation closeout is part of the definition of done.
