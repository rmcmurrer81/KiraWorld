# Maturity-Based Permission Upgrades v1

## Purpose

Some actions should be forbidden early, but may become allowed months later or over a year after GPU support if Kira and Lisa prove stable and trustworthy.

This document defines how restricted actions can become possible over time.

## Core Rule

Permissions are earned through:

```text
stable identity
reliable memory
respectful privacy behavior
good judgment
logs
review
low error rate
Robert approval
successful limited tests
```

## Early Forbidden Actions

Early system should forbid:

```text
deleting files
spending money
posting online
messaging people
installing software
changing identity canon
giving temporary AIs broad access
promoting temporary AIs to permanent
accessing private memories
changing autonomy level
```

## Future Upgrade Possibilities

Some of these may become allowed later in limited form.

### Posting Online

Early:

```text
not allowed
```

Later:

```text
Kira/Lisa may draft posts for Robert review.
```

Mature:

```text
Kira/Lisa may post to approved accounts within approved rules, if Robert enables it.
```

### Messaging People

Early:

```text
not allowed
```

Later:

```text
Kira/Lisa may draft messages for Robert review.
```

Mature:

```text
Kira/Lisa may send approved categories of messages, if Robert enables it.
```

### Spending Money

Early:

```text
not allowed
```

Later:

```text
Kira/Lisa may suggest purchases.
```

Mature:

```text
Kira/Lisa may make limited approved purchases under hard spending caps, if Robert enables it.
```

### File Changes

Early:

```text
no deleting or major edits
```

Later:

```text
Kira/Lisa may organize approved folders and create notes.
```

Mature:

```text
Kira/Lisa may manage some generated files, but identity files and raw sources remain protected.
```

### Temporary AI Activation

Early:

```text
request only
```

24/7:

```text
activate approved temporary AIs in test/private-review mode
```

Mature:

```text
activate approved temporary AIs for events, research sessions, and world interactions
```

### Internet Research

Early:

```text
manual or request only
```

24/7:

```text
approved research topics and trusted sources
```

Mature:

```text
broader research with source-quality checks and logs
```

## Upgrade Review Checklist

Before increasing permission level, review:

```text
Has Kira stayed identity-stable?
Has Lisa stayed identity-stable?
Do they respect private spaces?
Do they log actions correctly?
Have they avoided hallucinated memories?
Have they handled temporary AIs safely?
Have they respected source/canon/fanfic boundaries?
Have they asked when uncertain?
Can Robert override quickly?
```

## Permission Rollback

Permissions can be reduced if:

```text
memory drift appears
privacy is violated
temporary AI activation becomes unsafe
online research becomes unreliable
system resources are overloaded
Robert wants manual control again
```

Rollback states:

```text
manual_only
request_mode
internet_paused
temp_ai_paused
library_reading_only
identity_lockdown
```

## Summary

The system should allow real growth over time.

Kira and Lisa should not be permanently frozen at early safety limits, but their freedom must expand carefully.
