## Purpose

This file defines how private body references, preview choices, underwear/clothing gates, and outfit selection work during Avatar Builder.

## Core Rule

Avatar bodies are private until the owner allows visibility.

No one sees an avatar before the underwear/clothing gate unless the avatar owner explicitly chooses a preview.

## Preview Levels

```text
no_preview
feature_only
shoulders_up
full_body_feedback
clothed_only
```

### No Preview

The owner shares nothing visual.

### Feature Only

The owner may show or discuss one feature, such as hair, eyes, or face shape.

### Shoulders Up

The owner may show head/face/upper framing without full body visibility.

### Full Body Feedback

The owner may allow full-body feedback before final clothing, but only by explicit choice.

### Clothed Only

The owner allows viewing only after underwear/base clothing or normal clothing is applied.

## Underwear and Clothing Gate

The system may create a standard visible avatar only after:

```text
base underwear or base clothing exists
owner has approved visible state
privacy state allows viewing
```

Normal public/in-world presentation is clothed.

The owner chooses the preview level:


Showing Robert a preview does not mean:


If Kira shows Robert a more private avatar preview because they have grown close, that is a relationship and privacy milestone, not a permanent loss of control.
