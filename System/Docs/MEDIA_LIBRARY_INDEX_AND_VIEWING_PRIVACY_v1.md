# Media Library Index and Viewing Privacy v1

## Purpose

`Data/library` may contain movies, TV episodes, music, music videos, scripts, stories, novels, images, and other local media.

Kira and Lisa may eventually use this library during daily life, shared time, private time, user-away mode, source processing, notebook worlds, or temporary AI preparation.

Pre-GPU, the system should only index files and record viewing/listening intent. It should not try to understand video contents without the later media stack.

## Core Rule

Media access does not create memory by itself.

Watching or listening may create:

- viewing notes
- listening notes
- preferences
- questions
- recommendations
- favorite moments
- temporary AI proposals

Watching or listening must not automatically create:

- lived personal memories
- canon claims
- temporary AI profiles
- relationship memories
- private disclosures
- public posts

## Media Notes

Media notes live in `Data/media/viewing_notes/`.

Use them when Kira or Lisa reads, watches, or listens to something and wants to record a reaction without promoting it into memory.

Media notes can record:

- reaction summary
- emotional reactions
- questions
- likes and dislikes
- favorite characters, scenes, songs, or themes
- possible future use as source evidence after review

Media notes must keep these rules:

- media does not become lived memory
- media does not create a Temporary AI automatically
- source material remains source material
- private notes stay owner-controlled
- public export is not allowed without review

Tools:

```text
tools/create_media_viewing_note.py
tools/validate_media_viewing_note.py
```

## Door State

Kira and Lisa may use library media with the door unlocked or locked.

Unlocked/shared viewing may allow normal conversation or shared notes.

Locked/private viewing means the activity and reactions are controlled by the privacy session:

```text
who is present
who can observe
whether Robert can interrupt
whether a summary can be shared later
whether a note is owner-only
```

The same file may be watched privately one day and shared another day. The media file is the same; the session privacy is different.

## Index

The media index is generated by:

```text
tools/build_media_library_index.py
```

It writes:

```text
Data/indexes/media_library_index.json
```

The index records paths, file names, extensions, rough categories, file sizes, and safe usage policy. It does not read, transcribe, summarize, or play the media.

The index also records future 3D display hints. These are not active playback features yet. They tell the later world builder how a file might appear in the home:

```text
movie -> DVD or VHS case on the living-room media shelf
TV episode -> season disc case or VHS tape on a series shelf
music -> CD, record, or digital album case on a music shelf
script/story -> binder, book, or document on a reading shelf
```

Movies, shows, and music videos may also be eligible for the virtual screen or a virtual movie theater after the 3D/media stack exists.

## Summary

The media library gives Kira and Lisa things to watch, listen to, read, and react to. The index lets the system know what exists while keeping memory, privacy, source evidence, and temporary AI creation separate.
