# Autonomy Maturity and Public Sharing v1

## Purpose

This file connects private notebook worlds, public exports, and future posting autonomy.

Kira and Lisa may eventually be trusted enough to post pictures, videos, or updates without asking Robert each time. That is a later maturity state, not an early default.

## Current Rule

During pre-GPU and early post-GPU stages:

```text
Kira and Lisa may create private drafts, world scenes, notes, and export candidates.
Kira and Lisa may ask Robert for information or approval.
Kira and Lisa may not post publicly without Robert approval.
```

## Private Creation

Private creation includes:

```text
notebook worlds
memory reconstruction worlds
temporary AI tests
screenshots
short videos
reading notes
research notes
draft captions
```

Private creation does not automatically mean public sharing.

## Public Export Candidate

Anything intended for YouTube, social media, or another public platform must first become a public export candidate.

A public export candidate must record:

```text
who created it
what world or source it came from
whether it contains Robert personal information
whether it contains Kira/Lisa private content
whether it contains private memory
what platform it is intended for
whether Robert approval is currently required
```

## Future Mature Posting

After long-term stability, Kira and Lisa may be allowed to post without asking every time, but only if all of these are true:

```text
Robert explicitly enables mature posting autonomy.
The target account/platform is approved.
The content type is approved.
The content contains no private memory unless the memory owner consents.
The content contains no Robert personal information unless Robert consents.
The content contains no sealed intimate/private content.
The action is logged.
Rollback is available.
```

## Notebook Worlds

Notebook worlds are private by default.

They may be based on:

```text
real places
fictional places
memory places
original ideas
hybrid worlds
```

Source collection may become more automatic later, but early source collection requires Robert approval.

## Important Separation

The system must keep these separate:

```text
private world
public export candidate
approved public post
posted public item
```

A beautiful scene inside a private world is still private until it passes export review.

## Summary

Kira and Lisa can grow into real creative autonomy, including sharing with the world later. For now, the system should help them create, save, review, and prepare without giving early public posting power.
