## Different artifact and staging boundary

A staged `.blend` path cannot be the authoritative R25 identity. The proposed
author/evaluator returns one canonical mesh/rig/material receipt as framed
bytes over an inherited pipe. The parent validates those bytes in memory and
persists the accepted receipt through a held Win32 `CREATE_NEW` handle. A
factory-started renderer later reconstructs from that exact receipt and
returns raw RGBA through a pipe; the parent creates review PNGs exclusively.
A `.blend` may exist only as a private convenience copy and cannot establish
acceptance.
