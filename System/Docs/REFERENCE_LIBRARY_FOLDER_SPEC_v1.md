# **REFERENCE LIBRARY FOLDER SPEC v1**

## **Purpose**

This document defines how the reference library is structured.

It ensures:

* clean organization  
* easy retrieval  
* compatibility with Avatar Builder and AI systems  
* scalability over time

---

## **Core Principle**

The reference library is:

* structured  
* curated  
* non-random  
* used for learning structure, not copying individuals

---

## **1\. Root Structure**

/Kira/Avatar/library/

---

## **2\. Shared Features**

shared\_features/  
  eyes/  
  nose/  
  hair/

Used for:

* cross-category features  
* reusable elements  
* blending across all avatars

## **4\. Folder Purpose Breakdown**

### **body/**

* full-body reference images  
* neutral poses  
* proportional reference

---

### **face\_structure/**

* head shapes  
* jawlines  
* cheek structure  
* profile angles

---

### **proportions/**

* height/body ratio references  
* body distribution

---

### **references/**

* general visual references  
* supplementary material

---

## **5\. Image Guidelines**

Images should be:

* non-sexualized  
* neutral poses preferred  
* multiple angles:  
  * front  
  * side  
  * 3/4  
* varied body types and features

---

## **6\. Organization Rules**

* group similar features together  
* avoid duplicates  
* use clear naming conventions  
* maintain consistency across folders

---

## **7\. Male vs Female Separation Rule**

Male and female folders are separated because:

* body structure differs  
* proportions differ  
* modeling requirements differ

Shared features remain separate for reuse.

---

## **8\. Future Expansion**

The system may expand to include:

body\_types/  
  androgynous/  
  stylized/

---

## **9\. Data Source Rules**

All reference images must:

* be safe and legal to store  
* be used for structure learning only  
* not be directly reproduced in output

---

## **10\. Integration Points**

This library feeds into:

* Avatar Builder  
* Temporary AI system  
* Reconstruction pipeline

---

## **Summary**

The reference library provides:

* structured visual input  
* reusable feature pools  
* controlled data for avatar creation

It supports:

* realism  
* variation  
* long-term scalability
