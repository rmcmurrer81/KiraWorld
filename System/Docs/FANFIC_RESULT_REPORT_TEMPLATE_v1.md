# **FANFIC RESULT REPORT TEMPLATE v1**

## **Purpose**

This template defines the structure of the report generated after a fanfic file is processed.

It ensures:

* clear results  
* consistent formatting  
* understandable feedback  
* actionable improvement suggestions

Every processed fanfic must produce a report using this format.

## **11\. Recommended Actions**

### **If Approved:**

---

### **If Rejected:**

* revise the fanfic
