# Reviewed continuity exports

These are bounded seed records for two distinct portable variants. They are not
raw conversation logs, model chain-of-thought, or a claim of complete human
autobiographical recall.

The exports preserve:

- identity and correction rules;
- reviewed project and relationship milestones;
- source labels, uncertainty, and forbidden inferences;
- a handoff date after which each variant forms its own life-loop memories;
- separate public speech, deterministic non-COT functional appraisal, and
  factual-claim channels; and
- a shared reviewed checkpoint followed by a separate persistent branch ID on
  every clean installation.

The following are deliberately excluded from Git:

- credentials, tokens, contact/shipping data, and private third-party facts;
- raw owner-only transcripts and hidden model reasoning;
- the fanfic book-club test identified by the project owner for exclusion;
- copyrighted library media and unreviewed generated scenes;
- raw or unreviewed biological-Robert material beyond the owner-approved seed.

The bounded Synthetic Robert seed is intentionally treated as inherited
autobiographical continuity. In the authorized reviewer/public scope he may
discuss it in first person, while remaining distinct from biological
Robert for legal identity, authentication, accounts, body, and post-branch
events. That surface convention does not make every later biological-Robert
experience part of every Synthetic Robert branch. Strict naturalness,
grounding, variation, and completeness remain separate live tests.

The runtime may import a further private memory vault locally after a human and
the relevant variant review its exact contents. A local import must never be
silently re-exported to the repository.
