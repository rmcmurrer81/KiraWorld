# Room monitors 073 — static habitat workboards

This additive experimental backup contains the exact 58 source and dependency files of reviewed candidate 073. **Installed World 056 is unchanged.** It is a development and recovery snapshot, not an installed update, a finished Mars base or completed headset support.

The narrow five-file successor changes the EVA, laboratory and habitat screen content and its exact bindings. Each screen has one prominent **STATIC HABITAT SCENARIO** badge with an authored mission-day/shift context. EVA shows equipment identifiers, a suit checklist and battery percentages. The laboratory shows fictional regolith, dust and core sample queues. The habitat shows temperature and humidity targets, water quantity/capacity in litres and an air-filter task. These are original examples, not measurements, NASA observations, operating recommendations, live commands or simulated life-support results.

NASA reference facts and separately dated MEDA observations retain their original sources and dates. The airlock screen retains actual local controller state without asserting pressure or safety. Geometry, doors, materials, crop controls and source guards are unchanged from 072. The browser and portable-export copies of the monitor helper are identical; only the necessary producer/export digest and static-scenario contract metadata accompany the content change.

Independent source review found no blockers in this narrow delta. Seven Node scenario checks and three Python binding checks passed, covering values and units, immutable provenance, unchanged NASA/archive and door behavior, painting commands, exact five-file scope and source pins. CPU tests do not establish font rasterization, in-world legibility or artistic quality. **Actual 073 GLB export was pending at source freeze, and no 073 visual or headset approval is claimed here.** Later output evidence must be assessed separately.

A related actual 072 browser check passed the earlier reservoir screen/pipe correction, crop drawer width containment, crop selection and illustrative shade changes, plus paired-hatch traversal. It did not visually approve the new 073 workboard text. Materials, plant variation and wider typography still need assessment. Greenhouse shade only changes louver pose and an illustrative reading; there is no sunlight, heat or crop-growth simulation.

`SOURCE-INVENTORY.json` lists every source hash. The vendored Three.js license and package metadata remain beside the source. `REFERENCES.md` separates primary factual sources from fictional example state. This public payload excludes private sample geometry, saved worlds, personal paths and receipts, memories, model weights, credentials and generated media. `CPU-SUMMARY.json` records sanitized local review results; private fixtures and their test harnesses are intentionally not redistributed as a reproducible public test bundle.

Restoring these files does not install them. Existing owner worlds and immutable previews must retain their original bindings. Portable export includes static meshes, materials and linked metadata; a consumer runtime and hardware evaluation are still required for interaction or VR.
