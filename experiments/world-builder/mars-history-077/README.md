# Mars history library — experimental consumer077

This additive source snapshot preserves the uninstalled consumer077 and six original, source-reviewed Mars-history chapters. The chapters are dated **September 26, 2026** and distinguish historical events, current reports and future plans. Every narration entry is `null`: the transcripts and official source links work in the component, but no audio file, generated voice, listening approval or completed listening experience is included.

The Mars history entry is restricted to the current validated package room whose functional role is `habitat`. Opening it pauses walking and clears held movement and pointer input. Closing it requires an explicit walking resume. Crop-panel focus also pauses walking, including details summaries and links. Room exit, hidden pages, package changes and page disposal pause or dispose the library. A cancelled pending library fetch cannot reopen it later.

The library includes the narrow successor correction for queued native audio events: an old pause must not cancel a newer Play when the media element is already unpaused, and a stale playing event must not report playback while it is paused. The automated checks use inert media adapters, not real narration playback.

## Scope and recovery

`candidate/` contains the exact frozen consumer source, chapter manifest and necessary vendored Three.js files, with its MIT license. The package loader retains the two exact reviewed package-admission digests and all file/source, image-budget, geometry, door and navigation checks. **Admission has not been widened.** Private exported world packages and their source fixtures are omitted. An arbitrary public GLB will therefore be held by this experimental consumer; this bundle alone cannot reproduce the private package import tests or provide a world to walk through.

The application changes from consumer075 are confined to `app.mjs` and `index.html`; the history host, library module/CSS and chapter manifest are additions. The unchanged runtime continues to model session-local doors and paired-door sequencing, not pressure physics. No authoring-world geometry or installed application is changed by this backup.

`tests/` provides the portable inert component and app-lifecycle tests. The private-fixture consumer test and machine-specific runners/receipts are excluded. `TESTS.md` explains the portable subset and its limits. `SOURCE-INVENTORY.json` binds every included original source/test/research file to its frozen bytes. `REVIEW-SUMMARY.json` reports the local CPU and independent-review scope without copying private machine records.

`research/` retains the original chapter drafts and their current/future claim review. The runtime manifest preserves their transcript words while prefixing IDs with `chapter-` and selecting display source fields. Richer publication and observation dates remain in those research records. NASA/JPL/ESA/JAXA links are evidence, not agency endorsement. Review planned-mission dates again before recording or releasing this as current material.

This snapshot has no installed promotion, real narration, browser/visual acceptance or headset certification. Future audio requires actual asset integrity, duration, pronunciation and listening review. Future XR support must combine page and XR visibility reasons; the current component is a desktop consumer seam.

The publication manifest is prepared separately for root review. No source package here broadens existing model capabilities, trains a model, downloads a dependency or starts a service on import. The optional loopback `serve.py` remains explicit/manual and is not run by the backup process.
