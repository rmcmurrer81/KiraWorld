# Portable CPU checks

From this folder, use a modern Node.js runtime with `node:test` and `structuredClone` support:

```sh
node --test tests/airlock.test.mjs
```

No npm install, network, browser, WebGL, service, model or media is required. The suite has 16 cases using invented `demo:` identifiers, fake 64-character hash values and an explicit synchronous runtime double. It imports only the exact component and Node built-ins. No real world package or owner fixture is included.

Coverage includes metadata association rejection; genuine in-memory binding identity; initial unknown state; geometric closure versus fictional seals; both signed hinge directions; symbolic cycle completion; pause/resume token revocation; cancellation; bounded time; unexpected motion; changed runtime/byte identity; invalid observations; refused/asynchronous/unobserved commands; reentry; disposal; immutable snapshots; and the documented retained-pose display advisory.

A mock occupied-swing refusal verifies that refusal is propagated. It does not reproduce the real collision, occupancy, reach or navigation algorithm. The tests do not authenticate a GLB, walk a base, operate a real door, establish physical safety or validate a native UI. The original private producer suite and its source review are separate evidence; raw machine receipts are intentionally excluded.
