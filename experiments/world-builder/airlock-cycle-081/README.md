# Experimental fictional airlock cycle

This folder preserves the exact World081 JavaScript state component and a small portable CPU test suite. It adds symbolic `unknown`, `habitat` and `mars` states to an explicitly nominated two-door pair. Both doors must be closed and stopped, and their separate fictional seal acknowledgements must be set, before a timed cycle can begin. Pause, cancel, replacement and stale callback handling are explicit.

This is an unintegrated component backup. It does not install or change World Builder or the desktop package consumer. It includes no saved world, scene geometry, owner data, audio, video, model weights or visitor information. The artificial test metadata and hashes are invented for association tests; they cannot authenticate a real package.

The host remains responsible for verifying actual package/source/GLB bytes, normal collision and door rules, visible animation, clocks, focus and page lifecycle. This component delegates door commands through a captured synchronous runtime; it never sets hinge angles. All door entry points must be integrated consistently before an application can rely on the symbolic cycle.

The cycle is authored fiction. It implements no pressure units or equations, pump behavior, live sensor, seal test, mechanical latch, certified procedure or NASA design. The six-second default is a storytelling duration. Neither a room name nor a door order establishes a real Mars exterior. A host must disclose and explicitly nominate fictional sides.

**Display advisory:** after an observation error, `snapshot().doors` can retain the last successfully observed poses. Treat them as last observed/unavailable, never as fresh live door state. The component faults the cycle, clears symbolic pressure and seals, and will not authorize an opening while the observation is invalid. See [integration requirements](INTEGRATION.md).
