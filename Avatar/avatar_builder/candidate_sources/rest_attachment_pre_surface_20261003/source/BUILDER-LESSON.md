# Reusable Avatar Builder lesson: preserve a shared rest stage

Teach the builder to separate source eligibility, captured rest, attachment,
surface changes, pose validation and body readiness. A mesh's historical
capture is not a completed rig, and a completed in-process attachment is not a
saved, functioning body. The optional lane is a concrete source route for
reusing the selected generic producer/rest/compiler/backend without manual
bone-name guessing or old-carrier backfill.

1. Select the generic pre-surface mode explicitly. Obtain the independently
   reviewed root admission and finite origin/input/resource/output protocol.
   Check actual fresh scene ownership; refuse existing objects/data rather
   than deleting or rebinding them.
2. Bind the exact base and female macro recipe. Parse/transform with the
   selected producer helpers and retain each mesh/object allocation before
   later operations. Seed stable original IDs and capture global helper/joint
   rest points in the same axis/scale/floor frame as the body.
3. Add normalized default weights, then attach the selected rest plan before
   any intersection repair or custom surface changes. Preserve the original
   capture and prove the body points/weights/topology/matrix and named bones
   through the selected native consumer observations.
4. Record separate capture-time and attachment-time flags. Publish only the
   observed in-process stage; leave saved reload, deformation, movement,
   internal anatomy, sensory feedback and physiology visibly pending.
5. On failure retain the exact primary exception, body/rig/backend handles and
   underlying partial capture. Do not delete, retry, activate or reuse that
   scene. Root separately records cleanup and actual process return.
6. Before future external-surface work, design one coherent deformation for
   mesh, skeleton, organ/landmark positions and sensory anchors. Validate it
   with independent rest/pose/saved reload tests. The old surface operations
   are not approved merely because this pre-surface attachment completed.

The lesson currently describes source code and authored unrun fixtures. It is
not promoted to a qualified autonomous skill, builder registry entry, finished
avatar or Robert body. A later lesson acceptance should cite actual fixture,
native, saved reload and movement receipts, with failures retained and no
source-only claim converted into test or physiology evidence.
