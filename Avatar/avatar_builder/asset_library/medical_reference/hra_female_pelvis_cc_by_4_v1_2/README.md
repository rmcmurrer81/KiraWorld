# HRA female pelvic reference intake (CC BY 4.0, v1.2)

Status: **SOURCE REFERENCE ONLY — NOT A KIRA BODY OR FUNCTIONAL SYSTEM**

This folder preserves a bounded set of official Human Reference Atlas (HRA)
GLB reference objects downloaded on 2026-08-09. HRA describes the reference
objects as anatomically correct organ references developed from Visible Human
data, reviewed through its organ-reference process, and released under
Creative Commons Attribution 4.0 International.

Primary sources:

- https://humanatlas.io/3d-reference-library
- https://3d.nih.gov/entries/20984?version=1.01 (female pelvis)
- https://3d.nih.gov/entries/20995 (female urinary bladder)
- https://3d.nih.gov/entries/20996?version=1.02 (female uterus)
- https://www.nlm.nih.gov/research/visible/visible_human.html

Direct object URLs and exact hashes are in `SOURCE_MANIFEST.json`. All ten
files passed a GLB 2.0 header/declared-length/JSON-chunk parse. The intake
contains separately named structures for the pelvis, bladder, uterus/cervix,
left/right ovaries, left/right uterine tubes, left/right ureter/renal-pelvis
objects, and large intestine including rectum.

These files may guide scale, orientation, compartment ordering, and a
detachable private clinical-review module. They do not replace Kira's external
surface. They do not by themselves provide the vagina, urethra, anal canal,
pelvic-floor deformation, outlet attachment, continence, elimination,
menstruation, conception, pregnancy, sensation, health, or any biological
function. Missing structures must be modeled under the source-backed Kira
internal pelvic module contract, clearly labeled as authored clinical proxies,
and independently reviewed.

Any future derived asset must retain attribution, source URLs, exact source
hashes, and the CC BY 4.0 license notice. Do not use donor-specific dimensions
as a claim that one body represents all normal anatomy.
