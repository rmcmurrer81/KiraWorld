# HRA female whole-body reference intake (CC BY 4.0, v1.2)

Status: **SOURCE REFERENCE ONLY — NOT A COMPLETE KIRA BODY OR FUNCTIONAL SYSTEM**

This folder preserves eight versioned Human Reference Atlas (HRA) GLB
reference objects downloaded on 2026-08-20. HRA releases its CCF 3D reference
objects under Creative Commons Attribution 4.0 International. The objects are
derived from the NLM Visible Human Dataset and remain source references rather
than Kira-specific geometry.

Primary sources:

- https://hubmapconsortium.github.io/ccf/pages/ccf-3d-reference-library.html
- https://3d.nih.gov/users/hra
- https://www.nlm.nih.gov/research/visible/visible_human.html
- https://creativecommons.org/licenses/by/4.0/

`SOURCE_MANIFEST.json` records every direct versioned object URL, exact byte
count, SHA-256 digest, and mesh count. All eight files pass the GLB 2.0
magic/version/declared-length/JSON-chunk checks used by the anatomy preflight.

The intake adds female reference geometry for the kidneys, heart, blood
vasculature, lungs, small intestine, liver, and pancreas. It does **not**
complete a whole body. In particular, it does not supply the complete
mouth-to-stomach digestive route, a complete airway route, all nervous,
endocrine, lymphatic, immune, or musculoskeletal structures, carrier binding,
deformation evidence, or any biological function.

These objects may be used only as separately hash-bound, default-hidden source
geometry in a private inactive clinical-review module. Geometry never proves
eating, drinking, digestion, absorption, urination, respiration, circulation,
sensation, fertility, pregnancy, health, desire, consent, or lived experience.

Any derived asset must retain the HRA/HuBMAP attribution, the source URLs,
exact source hashes, the CC BY 4.0 license link, and an indication of changes.
Do not treat donor-derived dimensions as a claim that one body represents all
normal anatomy.
